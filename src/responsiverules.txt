Core Principles
Mobile-First: Start with mobile styles, enhance for larger screens

Consistent Breakpoints: Use Tailwind's default: sm: (640px), md: (768px), lg: (1024px), xl: (1280px)

Progressive Enhancement: Add features as screens get larger

Font Size Rules
Headings
Mobile: text-lg or text-xl

sm: text-xl or text-2xl

md: text-2xl or text-3xl

lg+: text-3xl, text-4xl, or custom sizes like text-[48px]

Body Text
Mobile: text-xs or text-sm

sm: text-sm or text-base

md+: text-base, text-[18px], text-[20px]

Line Heights
Mobile: leading-[110%] to leading-[140%]

Desktop: leading-[100%] to leading-[150%]

Spacing Rules
Padding
Horizontal: px-4 → sm:px-6 → md:px-8 → lg:px-12 → custom

Vertical: Scale proportionally: py-8 → sm:py-12 → md:py-16

Gaps
Mobile: gap-3 to gap-4

Desktop: gap-5 to gap-6 or custom like gap-[50px]

Section Heights
Use min-h-[size] for mobile, fixed h-[size] for desktop

Example: min-h-[400px] sm:min-h-[450px] md:min-h-[550px] lg:h-[619px]

Layout Rules
Grid/Columns
Mobile: grid-cols-1 (single column)

Desktop: lg:grid-cols-2 or lg:grid-cols-3 (multiple columns)

Flex Direction
Mobile: flex-col (stack vertically)

Desktop: md:flex-row or lg:flex-row (horizontal layout)

Component Rules
Buttons
Height: h-10 → sm:h-12 → md:h-14 → lg:h-[63px]

Width: Mobile: w-full, Desktop: sm:w-auto with max-w-[size]

Text: text-xs → sm:text-sm → md:text-base → lg:text-lg

Images & Icons
Logo: w-32 → sm:w-40 → md:w-48 → lg:w-[201px] (with h-auto)

Icons: Scale container and image proportionally

Backgrounds: Use object-cover with Next.js Image component

Forms
Inputs: w-full on mobile, natural width on desktop

Touch targets: Minimum h-10 or py-3 on mobile

Common Patterns
Show/Hide Elements: hidden lg:block

Text Alignment: text-center on mobile, sm:text-left on desktop

Width Limits: max-w-[90%] → sm:max-w-[80%] → md:max-w-[70%] → lg:max-w-full

Borders: Add only on larger screens: lg:border-l, lg:border-r

Quick Checklist
Mobile: Stack content, smaller text, full-width elements

Tablet: Adjust spacing, medium text sizes

Desktop: Multi-column layouts, larger text, optimized spacing

Always: Test touch targets, readability, and hover states
